# ZE CenterOS v1.1.2 — Teacher Filter on Weekly Schedule

## Added
- Admin and Academic Manager can filter the weekly center calendar by one teacher.
- Added an `Unassigned teacher` view for sessions that still need staffing.
- Weekly metrics now recalculate for the selected teacher.
- Previous/next/current-week navigation preserves the selected teacher.
- Student matching search preserves the active teacher filter.

## Deployment
Copy this hotfix over the current repository and push to `main`. No Supabase migration is required.
