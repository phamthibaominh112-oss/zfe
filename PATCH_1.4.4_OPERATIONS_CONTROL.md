# ZE CenterOS v1.4.4 — Operations Control

1. Enrollment Start/End date visible and editable per student.
2. CSKH renewal warning based on active enrollment End date (30-day window).
3. Midterm/Final warnings: Session 18 = Midterm, Session 36 = Final.
4. Quick Attendance command center with roster + one-click attendance + mark-all-present.
5. Duplicate previous week into viewed week; dates +7 days, session number continues, GV/TA copied.
6. Teacher availability Add/Edit/Delete preserves the currently viewed week and filters.
7. Class Planner + Dashboard warnings for classes missing Main Teacher or schedule.
8. Admin can override Teacher and Academic/CSKH Check-in/Check-out, with mandatory reason/audit fields.

No new SQL migration required; existing enrollment and workforce adjustment fields are reused.
